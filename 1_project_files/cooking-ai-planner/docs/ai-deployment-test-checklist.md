# 小饭桌 4.0 上线后测试清单

本文用于 Vercel 部署完成后做最终验收。建议分别测试“未配置 API Key 的 demo 模式”和“已配置 API Key 的真实 AI 模式”。

## 测试前准备

- 已从 GitHub 导入 Vercel。
- Vercel Root Directory 已设置为 `1_project_files/cooking-ai-planner`。
- Vercel Build Command 为 `npm run build`。
- Vercel Output Directory 为 `dist`。
- 如需测试真实 AI，Vercel 已配置 `AI_API_KEY`，并完成重新部署。

## 一、基础页面检查

- [ ] 首页可以打开。
- [ ] 页面没有白屏。
- [ ] 左侧导航、logo、首页主输入区和右侧工具区显示正常。
- [ ] 点击“开始做饭”入口后，主页面停留在可输入需求的状态。
- [ ] 输入框可以正常输入中文需求。

## 二、AI 生成流程检查

建议输入：

```text
我只有 15 分钟，预算 10 元，想做一个适合新手的晚饭。
```

- [ ] 点击“生成菜谱”后，按钮或页面出现 AI loading 状态。
- [ ] loading 结束后，页面没有卡死或白屏。
- [ ] AI answer 正常显示。
- [ ] 推荐 recipes 正常显示。
- [ ] 推荐菜谱至少包含菜名、说明、时间或难度等基础信息。
- [ ] cookingSteps 正常显示。
- [ ] tips 正常显示。

## 三、待购清单同步检查

- [ ] AI 结果里包含 shoppingList 数据。
- [ ] 生成完成后进入“待购清单”页面。
- [ ] 待购清单可以看到 AI 生成的食材。
- [ ] AI 清单分组或来源标识清晰。
- [ ] 勾选待购项后状态能变化。
- [ ] 删除待购项后页面能正常更新。
- [ ] 清空当前 AI 清单后，不影响页面其他功能。

## 四、收藏流程检查

- [ ] 在 AI 推荐菜谱中点击收藏按钮。
- [ ] 收藏按钮状态有变化。
- [ ] 进入“我的收藏”页面。
- [ ] 我的收藏页面可以显示刚收藏的 AI 菜谱。
- [ ] 刷新页面后，收藏记录仍然保留。
- [ ] 取消收藏后，收藏列表正常更新。

## 五、demo 模式检查

在未配置 `AI_API_KEY`，或临时移除 Vercel 环境变量后测试：

- [ ] 首页仍然可以生成内容。
- [ ] 页面出现 demo 模式提示。
- [ ] demo 模式下 AI answer 正常显示。
- [ ] demo 模式下推荐 recipes 正常显示。
- [ ] demo 模式下 shoppingList 可以同步到待购清单。
- [ ] demo 模式下 AI 推荐菜谱可以收藏。
- [ ] API 请求失败时页面不白屏。

## 六、真实 AI 模式检查

在 Vercel 配置 `AI_API_KEY` 并重新部署后测试：

- [ ] 生成结果不再是固定 mock 内容。
- [ ] 多次输入不同需求，AI answer 有对应变化。
- [ ] 推荐 recipes 与用户输入的时间、预算、设备约束相关。
- [ ] shoppingList 与推荐菜谱相关。
- [ ] Vercel Function 日志没有明显密钥泄露。
- [ ] 浏览器前端源码中看不到真实 API Key。

## 七、localStorage 与刷新检查

- [ ] 生成一次 AI 菜谱并同步待购清单。
- [ ] 收藏一个 AI 推荐菜谱。
- [ ] 刷新页面。
- [ ] 待购清单数据仍然保留。
- [ ] 我的收藏数据仍然保留。
- [ ] 最近做过、预算账本等已有本地数据功能未受影响。

## 八、移动端检查

建议使用浏览器 DevTools 模拟手机尺寸：

- [ ] 375px 宽度下页面可以正常滚动。
- [ ] 导航栏不遮挡主要内容。
- [ ] 首页输入框、生成按钮和计时器不重叠。
- [ ] AI 结果卡片在手机尺寸下可读。
- [ ] 待购清单和收藏页在手机尺寸下可操作。
- [ ] 弹窗没有按钮悬空或超出屏幕的问题。

## 九、控制台与网络检查

- [ ] 浏览器 Console 没有持续报错。
- [ ] Network 中 `/api/ai` 请求存在。
- [ ] 无 API Key 时 `/api/ai` 返回 demo/mock 结果，而不是导致页面崩溃。
- [ ] 有 API Key 时 `/api/ai` 返回真实 AI 结果。
- [ ] 没有加载失败的关键 JS/CSS 资源。
