# 小饭桌 4.5 Step 2 执行记录

日期：2026-05-24

## 执行目标

优化“本月省钱计划”弹窗，让本月项目记录支持编辑和删除，并在修改后自动同步 localStorage 与预算统计。

## 修改原因

当前省钱计划可以新增做饭开支，但“本月项目记录”只能查看，无法修正金额、备注或误录项目。用户一旦记错，只能继续新增记录，导致本月已花、剩余预算和预算状态不准确。

## 实际修改

- 在预算账本 hook 中新增：
  - `updateExpense(expenseId, patch)`
  - `deleteExpense(expenseId)`
- 编辑记录支持修改：
  - 金额
  - 名称 / 备注
  - 日期
- 删除记录前使用 `window.confirm()` 二次确认。
- 编辑或删除后自动触发 ledger 更新，`deriveBudgetStats()` 会重新计算：
  - 本月已花
  - 剩余预算
  - 预算使用比例
  - 当前预算状态
- 弹窗记录卡右侧新增“编辑 / 删除”操作入口。
- 编辑态使用卡片内联表单，不额外增加复杂弹窗。
- 移动端下记录卡和编辑表单自动纵向排列，避免按钮溢出。

## 预算数据结构

localStorage key：

```text
cooking_ai_planner.v3.budget_ledger.v1
```

账本结构保持兼容：

```js
{
  monthlyBudget: number | string,
  expenses: [
    {
      id: string,
      amount: number,
      note: string,
      date: string,
      updatedAt?: string
    }
  ],
  updatedAt: string
}
```

本步骤未改变原有 `expenses` 数组结构，只在编辑后的单条记录上补充可选 `updatedAt`。

## 删除和编辑逻辑

编辑：

- 根据 `expenseId` 查找目标记录。
- 校验金额必须大于 0。
- 校验日期必须可被解析。
- 保留原 `id`，只更新金额、备注、日期和 `updatedAt`。
- 写回 `expenses` 数组后同步 localStorage。

删除：

- 根据 `expenseId` 查找目标记录。
- 删除前弹出确认提示。
- 确认后从 `expenses` 数组中过滤目标记录。
- 同步更新 `updatedAt`。

## 数据影响

- 会修改 `cooking_ai_planner.v3.budget_ledger.v1` 中的 `expenses`。
- 不影响其他 localStorage key。
- 不影响 AI、待购清单、收藏或任务 XP 数据。
- 预算统计不单独存储，仍由 `deriveBudgetStats()` 从 ledger 实时推导。

## UI影响

- 本月项目记录右侧新增操作按钮。
- 点击“编辑”后，当前记录卡展开为内联编辑表单。
- 点击“删除”前会出现浏览器确认框。
- 移动端下记录卡纵向排列，按钮保留在卡片内部。
- 当前弹窗整体视觉风格、圆角、暖色体系保持不变。
