# 小饭桌 4.5 Step 4 执行记录

日期：2026-05-24

## 执行目标

修复“已加入待购清单”成功弹窗底部按钮布局异常，确保两个按钮等宽、文字横向显示，并完整位于弹窗内部。

## 修改原因

原弹窗复用通用 `actionsRow`，同时 `primaryBtn` 默认有 `width: 100%` 与 `margin-top`，在弹窗底部并排布局时容易出现按钮宽度挤压、文字竖排或按钮超出弹窗内容区的问题。

## 实际修改

- 为加入待购清单成功弹窗新增独立类名：
  - `addShoppingModal`
  - `addShoppingModal__actions`
- 底部按钮区改为 CSS Grid：
  - 桌面端：两列等宽
  - 窄屏端：一列上下排列
- 弹窗内按钮统一设置：
  - `width: 100%`
  - `min-width: 0`
  - `margin-top: 0`
  - `display: inline-flex`
  - `white-space: nowrap`
  - `writing-mode: horizontal-tb`
- 增加弹窗自身最大宽度和 padding，避免按钮贴边或悬空。
