# 小饭桌 4.6 Step 2 执行记录

日期：2026-05-24

## 执行目标

修复推荐任务完成后的空状态展示，并增加“刷新推荐任务”入口，避免任务区只剩单张不可操作的完成卡片。

## 修改原因

4.5 已修复推荐任务与 XP 的基础逻辑，但当当前推荐任务全部完成后，页面仍可能只展示一张“今日任务已完成”卡片，缺少继续探索任务的入口。4.6 需要让空状态更清晰，并提供刷新动作。

## 实际修改

- 重写 `RecommendedTasksPanel.jsx` 的空状态分支。
- 新增 `refreshSeed` 状态，用于触发推荐任务重新排序。
- 接入 `getAvailableTaskCount()` 判断是否仍有未完成任务。
- 点击“刷新推荐任务”后更新 seed，重新调用 `getRecommendedTasks()`。
- 难度切换时同步刷新 seed，避免任务列表停留在旧顺序。
- 当没有可推荐任务时，显示 `暂时没有可推荐任务，请稍后再试。`。

## 文案影响

新增 / 调整文案：

- `已完成今日训练，可以继续挑战新的练习任务。`
- `刷新推荐任务`
- `暂时没有可推荐任务，请稍后再试。`
- 保留任务难度、等级、阶段信息。

## UI 影响

- 空状态不再复用普通完成任务卡片。
- 新增 `.taskPanel__empty`、`.taskPanel__emptyTitle`、`.taskPanel__emptyText`、`.taskPanel__emptyMeta`、`.taskPanel__refreshBtn` 样式。
- 空状态保持暖白卡片、圆角、轻边框与当前任务面板风格一致。

## 数据影响

- 未新增 localStorage key。
- 推荐任务仍根据 `cooking_ai_planner.v3.task_progress.v1` 中的 `completedTaskIds` 排除已完成任务。
- `refreshSeed` 是组件内临时 UI 状态，不持久化。
- 与 4.5 任务修复关系：本步保留 4.5 的 XP / 等级 / 完成任务排除逻辑，只补充空状态与刷新入口。

## 任务刷新逻辑

- `getRecommendedTasks()` 已支持 `seed` 参数。
- 刷新按钮通过 `setRefreshSeed(seed + 1)` 改变任务排序。
- 已完成任务继续被 `completedTaskIds` 排除，避免重复刚完成任务。
- 若所有任务都已完成，则按钮禁用，并显示暂无可推荐任务文案。
