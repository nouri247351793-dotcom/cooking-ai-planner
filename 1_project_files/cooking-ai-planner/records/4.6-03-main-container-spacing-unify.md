# 小饭桌 4.6 Step 3 执行记录

日期：2026-05-24

## 执行目标

统一主页右侧主内容容器的上、右、下、左边距，减少顶部和左右间距不一致导致的视觉偏移。

## 修改原因

主页使用 `appShell--wide` 宽布局。原桌面端布局中，外层容器 padding 与 `appMain` 的 `padding-top` 会叠加，导致顶部视觉间距大于左右边距，页面重心偏上且边距不统一。

## 实际修改

- 在桌面端为 `.appShell--wide` 设置统一 padding：
  - `padding: var(--gap-columns);`
- 在桌面端取消首页 wide 容器内 `.appMain` 的额外顶部 padding：
  - `.appShell--wide .appMain { padding-top: 0; }`
- 保持内部卡片之间的 `gap` 不变。
- 保持移动端主布局不变。

## 涉及文件

- `1_project_files/cooking-ai-planner/src/styles/app.css`
- `1_project_files/cooking-ai-planner/records/4.6-03-main-container-spacing-unify.md`

## 文案影响

无文案变更。

## UI 影响

- 桌面端主页右侧大容器边距统一为 `var(--gap-columns)`，当前 token 值为 `24px`。
- 首页顶部不再额外叠加 `appMain` 的顶部间距。
- 首页内部模块间距保持原有 `homeV2` / `gap` 规则，不压缩主要内容。

## 数据影响

无 localStorage、路由或业务状态变更。

## 原边距问题

- `.appShell` 在桌面端已有 padding。
- `.appMain` 又额外设置 `padding-top: var(--gap-module)`。
- 首页 wide 布局不显示顶部 Header，因此顶部间距比左右边距更大。

## 新边距设置

```css
@media (min-width: 900px) {
  .appShell--wide {
    padding: var(--gap-columns);
  }

  .appShell--wide .appMain {
    padding-top: 0;
  }
}
```
