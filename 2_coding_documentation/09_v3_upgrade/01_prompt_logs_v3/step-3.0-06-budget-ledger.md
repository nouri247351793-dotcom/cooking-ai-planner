## Expanded Execution Prompt

```text
请实现 3.0 版省钱计划模块，对齐 PRD 3.0。

要求：
1. 首页右侧“省钱计划”卡片只展示本月预算、本月已花和一个进度条。
2. 点击省钱计划卡片后打开“省钱计划”弹窗。
3. 首次进入时，若尚未设置预算，则先填写本月预算。
4. 后续进入时默认展示本月预算概览，可新增一条“本次做饭开支”，可修改本月预算。
5. 每条开支记录至少包含 id、amount、note（可选）、date。
6. 系统自动计算本月总开支、剩余预算、使用比例。
7. 弹窗内展示本月预算、本月已花、剩余预算、当前状态、新增开支输入区、本月项目记录列表。
8. 首页不显示剩余预算和状态，只显示摘要。
9. 数据先保存到 localStorage。
10. 同步更新文档，明确首页卡片为什么只保留摘要，预算与任务系统为什么要解耦。
```

## AI Execution Notes

- 本轮只实现本地预算账本，不接真实支付、购物平台或云端同步。
- 首页预算卡保持轻摘要，复杂录入和状态判断全部收进弹窗。
- 预算账本与任务 XP 使用不同 localStorage key，避免成长系统和财务记录互相耦合。
