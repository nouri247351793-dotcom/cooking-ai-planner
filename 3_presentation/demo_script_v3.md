# 小饭桌 3.0 Demo Script

Date: 2026-05-23

## 1. 开场

这次 3.0 的重点不是接真实 AI，而是把小饭桌从 2.0 的菜谱生成工具升级为一个新手做饭 dashboard。

一句话介绍：

> 小饭桌 3.0 帮新手把“想吃什么、怎么练、怎么计时、怎么省钱、怎么复盘”放到同一个界面里。

## 2. 首页 Dashboard

演示路径：

1. 打开首页。
2. 展示左侧 icon nav。
3. 展示中间深底主输入区。
4. 展示右侧工具区。

讲解点：

- 中间是主操作：告诉系统今天想吃什么。
- 右侧是轻工具：计时器、随机一道菜、贴士、省钱计划。
- 下方是成长任务：从“看菜谱”转向“做练习”。

## 3. 生成菜谱

演示输入：

```text
我只有 20 分钟，预算不高，想练一道简单下饭菜。
```

演示动作：

1. 点击“生成菜谱”。
2. 进入结果页。
3. 点击一个菜谱进入详情。

讲解点：

- 3.0 当前仍是 mock / 本地规则，不接真实 AI。
- 重点是演示完整信息结构和页面流转。

## 4. 推荐任务与 XP

演示动作：

1. 回首页。
2. 查看“推荐任务”。
3. 切换简单 / 中等 / 困难。
4. 点击“查看小教程”。
5. 在任务详情页点击“我做了”。

讲解点：

- 简单 +5 XP，中等 +10 XP，困难 +15 XP。
- 用户手动确认完成，系统不伪装真实识别。
- XP 会更新等级和阶段。

## 5. 计时器

演示动作：

1. 点击时间区域修改 MM:SS。
2. 点击开始计时。
3. 暂停或重置。

讲解点：

- 计时器是高频做饭工具，所以放在右侧工具区第一位。
- 当前不持久化，刷新后重置。

## 6. 省钱计划

演示动作：

1. 点击“省钱计划”。
2. 如果首次进入，设置本月预算。
3. 记录一条本次做饭开支。
4. 查看本月已花、剩余预算、使用比例。

讲解点：

- 预算账本和任务 XP 解耦。
- 预算是钱，XP 是学习成长，不能混在一个状态里。

## 7. 辅助页面

依次展示：

- 待购清单
- 我的收藏
- 最近做过
- 新手贴士

讲解点：

- 这些不是主生成流程，而是辅助复盘、准备和沉淀。
- 3.0 已统一一级页面的 hero、卡片和空状态。

## 8. 结束

总结：

- 3.0 完成了 dashboard 化。
- 完成任务成长闭环。
- 完成预算账本闭环。
- 完成 UI token 与组件规范。
- 后续如果进入 4.0，可以接真实 AI、图片识别和云端同步。
