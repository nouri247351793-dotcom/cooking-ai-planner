# 小饭桌 cooking-ai-planner

小饭桌是一款面向大学生的 AI 做饭规划前端原型。用户可以输入自己的做饭目标，例如省钱、快手、宿舍设备受限、想练习做饭等，系统会根据目标生成菜谱建议，并围绕「选菜、备料、执行、复盘」组织完整的做饭流程。

当前项目主要用于课程展示、产品原型演示和开发过程归档。

## 核心功能

- 首页输入做饭目标，生成菜谱推荐
- 支持按时间、预算、设备、份数等条件筛选
- 菜谱结果页展示推荐结果和生成条件
- 菜谱详情页展示食材、调料和步骤
- 支持将食材加入待购清单
- 支持收藏菜谱
- 支持记录“我做了”，形成最近做过记录
- 待购清单支持分组、勾选、编辑、删除和进度展示
- 收藏页支持搜索、筛选和本地导出
- 新手贴士页提供基础做饭技巧
- 设置页提供 AI 模型配置入口
- 数据通过浏览器 localStorage 本地保存

## AI 功能说明

当前项目已预留 AI 服务配置入口，可用于对接 OpenAI-compatible 服务。  
在未配置真实模型服务或接口不可用时，项目仍可通过 mock 数据完成主要演示流程。
